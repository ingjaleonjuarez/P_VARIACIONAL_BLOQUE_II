PUBLICACIÓN EN GITHUB PAGES
1. Sube index.html y MEMO_insignia_central.png a la raíz del repositorio.
2. Puedes subir también LEEME_GitHub.txt como referencia.
3. En GitHub abre Settings > Pages.
4. Selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta / (root).
6. Guarda la configuración.
7. Espera la publicación y abre la URL de GitHub Pages.

DEPENDENCIAS
- El simulador no requiere archivos JavaScript locales externos.
- No requiere hojas CSS externas locales.
- La generación de QR está integrada en el propio HTML.
- La única imagen local externa requerida es MEMO_insignia_central.png.
- El enlace "Cuéntanos tu experiencia" abre Google Forms y requiere internet.
