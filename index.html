H1 · Derivación por definición

MEMO · Construye la derivada desde la definición y comprueba cada transformación.

Microlección H1 · Derivar desde la definición

1. Sustituye x por x + h

Calcula f(x+h) respetando paréntesis, potencias y signos.

2. Resta las funciones

Construye f(x+h) − f(x) y simplifica términos semejantes.

3. Divide entre h

Forma el cociente [f(x+h)−f(x)]/h. Antes del límite debe ser posible cancelar el factor h.

4. Calcula el límite

Solo después de simplificar, toma h → 0. El resultado es f′(x).

5. Comprueba

Contrasta tu resultado con una regla directa cuando ya la conozcas; ambos caminos deben coincidir.

Ruta útil: sustituye → resta → divide → simplifica → límite.

H2 · Reglas de derivación

MEMO · Decide qué regla corresponde antes de derivar y revisa dominio, signos y función interior.

Microlección H2 · Elegir y combinar reglas

1. Observa la operación principal

Antes de derivar decide si la función es una suma, un producto, un cociente o una composición.

2. Potencia

d(xⁿ)/dx = nxⁿ⁻¹. Las constantes derivan a cero y las sumas se derivan término a término.

3. Producto y cociente

(uv)′ = u′v + uv′ y (u/v)′ = (u′v − uv′)/v². En cocientes conserva las restricciones del dominio.

4. Cadena

Si una función está dentro de otra, deriva la parte externa y multiplica por la derivada de la función interior.

5. Verifica tu estrategia

Escribe qué regla usaste y revisa signos, paréntesis, dominio y función interior.

Ruta útil: observa → reconoce → descompón → deriva → verifica.

H3 · Derivadas trigonométricas

MEMO · Reconoce la derivada trigonométrica básica y combina la cadena cuando sea necesario.

Microlección H3 · Derivadas trigonométricas

1. Tres derivadas básicas

(sen x)′ = cos x, (cos x)′ = −sen x y (tan x)′ = sec² x.

2. La cadena sigue presente

Si aparece sen(u), cos(u) o tan(u), multiplica por u′(x).

3. Combina reglas

Una función trigonométrica puede formar parte de un producto o cociente. Identifica primero la operación principal.

4. Cuida signos

La derivada de coseno introduce un signo negativo. En expresiones como −cos(u), ese signo puede cambiar al derivar.

5. Revisa el dominio

La tangente y la secante requieren cos(u) ≠ 0.

Ruta útil: trigonométrica básica → función interior → regla principal → dominio.

H4 · Rolle y teorema del valor medio

MEMO · Verifica las hipótesis antes de buscar el punto c y explica qué representa la pendiente.

Microlección H4 · Rolle y teorema del valor medio

1. Verifica antes de calcular

Ambos teoremas requieren que la función sea continua en [a,b] y derivable en (a,b).

2. Rolle añade una condición

Además exige f(a)=f(b). Entonces existe al menos un punto interior con f′(c)=0.

3. Valor medio compara pendientes

Existe un c interior tal que f′(c)=[f(b)−f(a)]/(b−a).

4. c debe estar dentro

Una solución algebraica solo es válida para el teorema si pertenece al intervalo abierto (a,b).

5. Una gráfica no sustituye las hipótesis

Un dibujo puede sugerir una tangente, pero primero debes justificar continuidad y derivabilidad.

Ruta útil: hipótesis → pendiente requerida → deriva → resuelve f′(c) → verifica c ∈ (a,b).
